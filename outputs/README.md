# Academy of Leaders: The Newspaper

Static school newspaper pages built with HTML, CSS, and JavaScript.

## Pages

- `index.html` — front page
- `announcements.html` — notices
- `school-life.html` — school life and events
- `beyond.html` — beyond the classroom
- `articles/` — individual story pages

## GitHub Pages

This site has no build step. In the repository settings, enable GitHub Pages from the `main` branch and the repository root (`/`). GitHub Pages serves `index.html` and the linked page files directly.
